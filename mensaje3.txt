Requisitos para que funcione en producción:

 • Instalar omnivoice en el mismo Python que ejecuta la API:


   pip install omnivoice

   # o desde GitHub:

   pip install git+https://github.com/k2-fsa/OmniVoice.git

 • Instalar también torch con CUDA y soundfile/numpy.
 • Asegurarse de que OMNIVOICE_USE_MOCK=false en producción.
 • La primera vez descargará el modelo de HuggingFace (~varios GB).

Limitaciones conocidas:

 • OmniVoice no soporta emotion/intensity directamente en generate(). Se aceptan los parámetros pero se ignoran (voice design cubre parcialmente el caso).
 • Las "voces stock" son aproximaciones vía instruct; no son voces reales pre-entrenadas con esos IDs.
 • El warmup real está deshabilitado por defecto (OMNIVOICE_WARMUP_ON_START=False) porque es costoso.
