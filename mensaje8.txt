8. Problemas frecuentes

8.1 torch.cuda.is_available() devuelve False

 • Verifica que el driver NVIDIA soporta CUDA 12.1: nvidia-smi.
 • Reinstala torch con el --index-url correcto.
 • Comprueba que la variable OMNIVOICE_DEVICE=cuda:0 está en .env.

8.2 undefined symbol _ZN3c106detail23torchLibraryImpl...

Mismatch entre torch y torchaudio. Solución:



# Reinstalar torch y torchaudio con la misma versión CUDA

pip uninstall -y torch torchaudio

pip install torch==2.4.0+cu121 torchaudio==2.4.0+cu121 --index-url https://download.pytorch.org/whl/cu121


8.3 RuntimeError: CUDA error: no kernel image is available

La versión de torch no tiene kernels para tu GPU. Para P2000 (Pascal, CC 6.1)

usa CUDA 11.8 o 12.1, nunca 12.4+.

8.4 La API arranca pero /health devuelve mode: "MOCK"

El motor real falló al inicializar. Revisa los logs al arrancar y el campo

real_engine_error en /health. Las causas más comunes:

 • torch no instalado en el venv externo.
 • Versión de torch incompatible con la GPU.
 • OmniVoice no instalado (pip install -e . no se ejecutó).

8.5 OSError: [WinError 126] al cargar DLLs de CUDA

Falta el runtime de CUDA en el sistema. Instala

CUDA Toolkit 12.1

o asegúrate de que torch incluye los DLLs necesarios.
